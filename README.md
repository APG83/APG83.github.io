## Artifact Overview

The original Contact Service application allowed contact records to be added, updated, retrieved, and deleted while validating required contact information.

The artifact was enhanced in three areas:

### Software Design and Engineering

The application was reorganized into separate model, validation, repository, and service components. Logging, dependency injection, stronger validation, clearer documentation, and expanded JUnit testing were added.

### Algorithms and Data Structures

The application was enhanced to use a HashMap for efficient contact lookup by ID. Sorting functionality was also added to provide ordered contact results when needed.

### Databases

SQLite database persistence was added so contact records remain available after the application closes. The database implementation supports create, read, update, and delete operations using parameterized SQL statements.
