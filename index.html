Software Design and Engineering

The software design and engineering enhancement improves the organization, readability, maintainability, and testability of the Contact Service application. The enhanced design separates the model, service, validation, and repository responsibilities while adding clearer documentation and application logging.

Algorithms and Data Structures

The algorithms and data structures enhancement uses a HashMap to improve contact lookup, update, and deletion operations. The application also supports sorting contact records by name while preserving efficient ID-based access.

Artifact and narrative coming soon.

Databases

The database enhancement adds SQLite persistence to the Contact Service application. Contact information is stored in a relational database and remains available after the application closes. Parameterized SQL statements are used to support secure create, read, update, and delete operations.
